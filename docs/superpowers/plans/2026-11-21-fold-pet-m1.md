# FoldPet M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the M1 slice of FoldPet — a local Mac bridge that ingests Claude Code hook events, serves a zero-install phone page showing a clock and a live Petdex sprite, with WiFi LAN pairing, local/Petdex pet catalog, and a doctor command.

**Architecture:** A Node/TypeScript bridge exposes a loopback-only event endpoint for agent adapters, an authenticated HTTP/WebSocket API for the phone, and serves a Vite-built static page. Events are normalized into six phases, aggregated into multi-session state, and mapped to the nine Petdex sprite states. The phone is a browser page with folded/wide responsive layouts. Pets come from `~/.codex/pets`, `~/.fold-pet/pets`, or the cached Petdex manifest.

**Tech Stack:** Node 20+ / TypeScript (NodeNext), `ws`, `qrcode-terminal`, Vite + vanilla TS/Canvas, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-21-fold-pet-design.md`

**Scope:** This plan delivers milestone **M1 only** (bridge + Claude Code adapter + phone display + pet catalog + QR/doctor + Qoder research gate). M2 (Codex/OpenCode/Pi adapters), M3 (Qoder adapter, upload UI, BT tethering polish), and M4 (device acceptance polish) get separate plans after M1 is verified. BT PAN transport needs no M1 code — the bridge binds `0.0.0.0`, so it works over any IP path; M3 only adds the guided flow.

## Global Constraints

- Node.js >= 20. Bridge is macOS-only in v1; phone page must run on iOS Safari 16.4+ and Android Chrome.
- Phone is display-only: no approvals, prompts, or agent control.
- No cloud, no accounts, no telemetry. Only external calls: Petdex manifest and Petdex asset proxy.
- `POST /api/event` accepts loopback connections only. Every other route requires the bridge token (Bearer, cookie, or one-time `?token=` bootstrap).
- Event payload only: agent, sessionId, project (basename), phase, optional tool, optional detail, ts. Never code, prompts, or outputs.
- Petdex atlas: 8 columns; frame 192×208; 9 rows (v1) or 11 rows (v2). Rows: 0 idle, 1 running-right, 2 running-left, 3 waving, 4 jumping, 5 failed, 6 waiting, 7 running, 8 review.
- Frame counts/durations (ms): idle [280,110,110,140,140,320]; running-right/left 8×[120…220]; waving 4×[140…280]; jumping 5×[140…280]; failed 8×[140…240]; waiting 6×[150…260]; running 6×[120…220]; review 6×[150…280].
- UI copy Traditional Chinese; code, identifiers, and comments English.
- No fabricated acceptance evidence. Playwright fixture pets are test fixtures, not acceptance; real acceptance uses real agent sessions.
- Petdex code is MIT; pet art is owned by submitters — local/personal use only.
- Playwright browser download (~150 MB) and `npm link` are one-time local installs; if declined, mark the affected step NOT RUN, never silent-skip.

import { randomBytes } from "node:crypto";
import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";

export type QuietHours = { start: string; end: string };
export type Config = {
  token: string;
  port: number;
  activePet: string | null;
  sleepAfterMinutes: number;
  quietHours: QuietHours | null;
};

export function foldPetHome(env: NodeJS.ProcessEnv = process.env): string {
  return env.FOLDPET_HOME ?? join(homedir(), ".fold-pet");
}

export function configPath(home: string): string {
  return join(home, "config.json");
}

export function ensureConfig(home: string): Config {
  mkdirSync(join(home, "pets"), { recursive: true });
  mkdirSync(join(home, "cache", "petdex"), { recursive: true });
  mkdirSync(join(home, "logs"), { recursive: true });
  if (existsSync(configPath(home))) return loadConfig(home);
  const config: Config = {
    token: randomBytes(32).toString("base64url"),
    port: 7788,
    activePet: null,
    sleepAfterMinutes: 10,
    quietHours: null,
  };
  saveConfig(home, config);
  return config;
}

export function loadConfig(home: string): Config {
  const parsed = JSON.parse(readFileSync(configPath(home), "utf8")) as Partial<Config>;
  if (typeof parsed.token !== "string" || parsed.token.length < 16) throw new Error("config.token missing or too short");
  const port = parsed.port ?? 7788;
  if (!Number.isInteger(port) || port < 0 || port > 65535) throw new Error("config.port invalid");
  return {
    token: parsed.token,
    port,
    activePet: parsed.activePet ?? null,
    sleepAfterMinutes: parsed.sleepAfterMinutes ?? 10,
    quietHours: parsed.quietHours ?? null,
  };
}

export function saveConfig(home: string, config: Config): void {
  mkdirSync(home, { recursive: true });
  writeFileSync(configPath(home), JSON.stringify(config, null, 2) + "\n");
}
```

export const PHASES = ["started", "working", "waiting", "review", "done", "failed", "idle"] as const;
export type Phase = (typeof PHASES)[number];

export const AGENTS = ["claude", "codex", "opencode", "pi", "qoder"] as const;
export type AgentId = (typeof AGENTS)[number];

export interface NormalizedEvent {
  v: 1;
  agent: AgentId;
  sessionId: string;
  project: string;
  phase: Phase;
  tool?: string;
  detail?: string;
  ts: number;
}

const MAX_TEXT = 120;

function text(value: unknown): string | null {
  if (typeof value !== "string") return null;
  const trimmed = value.trim();
  return trimmed.length > 0 && trimmed.length <= MAX_TEXT ? trimmed : null;
}

export function parseEvent(value: unknown): NormalizedEvent | null {
  if (typeof value !== "object" || value === null) return null;
  const v = value as Record<string, unknown>;
  if (v.v !== 1) return null;
  const agent = AGENTS.includes(v.agent as AgentId) ? (v.agent as AgentId) : null;
  const sessionId = text(v.sessionId);
  const project = text(v.project);
  const phase = PHASES.includes(v.phase as Phase) ? (v.phase as Phase) : null;
  const ts = typeof v.ts === "number" && Number.isFinite(v.ts) ? v.ts : null;
  if (!agent || !sessionId || !project || !phase || ts === null) return null;
  const event: NormalizedEvent = { v: 1, agent, sessionId, project, phase, ts };
  const tool = text(v.tool);
  if (tool) event.tool = tool;
  const detail = text(v.detail);
  if (detail) event.detail = detail;
  return event;
}
```

import { basename } from "node:path";
import type { NormalizedEvent, Phase } from "../events.js";

function str(value: unknown): string | null {
  return typeof value === "string" && value.trim() !== "" ? value.trim() : null;
}

export function mapClaudeHook(input: unknown, now = Date.now()): NormalizedEvent | null {
  if (typeof input !== "object" || input === null) return null;
  const data = input as Record<string, unknown>;
  const sessionId = str(data.session_id);
  const cwd = str(data.cwd);
  const hookEvent = str(data.hook_event_name);
  if (!sessionId || !cwd || !hookEvent) return null;

  let phase: Phase;
  switch (hookEvent) {
    case "SessionStart": phase = "started"; break;
    case "UserPromptSubmit": phase = "working"; break;
    case "PreToolUse":
    case "PostToolUse": phase = "working"; break;
    case "Notification": phase = "waiting"; break;
    case "SubagentStop": phase = "working"; break;
    case "Stop": phase = "done"; break;
    case "SessionEnd": phase = "idle"; break;
    default: return null;
  }

  const event: NormalizedEvent = {
    v: 1,
    agent: "claude",
    sessionId,
    project: basename(cwd).slice(0, 120) || "project",
    phase,
    ts: now,
  };
  const tool = str(data.tool_name);
  if (tool && tool.length <= 120) event.tool = tool;
  return event;
}

```ts
import type { AgentId, NormalizedEvent, Phase } from "./events.js";

export const PET_STATES = ["idle", "running-right", "running-left", "waving", "jumping", "failed", "waiting", "running", "review"] as const;
export type PetState = (typeof PET_STATES)[number];

export interface SessionView {
  key: string;
  agent: AgentId;
  sessionId: string;
  project: string;
  phase: Phase;
  tool?: string;
  startedAt: number;
  lastEventAt: number;
}

export interface Snapshot {
  type: "snapshot";
  now: number;
  pet: PetState;
  sessions: SessionView[];
  activePet: string | null;
  sleepAfterMinutes: number;
  quietHours: { start: string; end: string } | null;
}

type Extra = { sleepAfterMinutes: number; quietHours: { start: string; end: string } | null };
type Flash = { state: PetState; until: number };
type Options = { now?: () => number; ttlMs?: number; flashMs?: number; waveMs?: number };

const PHASE_ORDER: Record<Phase, number> = { waiting: 0, working: 1, review: 2, done: 3, failed: 4, started: 5, idle: 6 };

export class Aggregator {
  private readonly sessions = new Map<string, SessionView>();
  private flash: Flash | null = null;
  private readonly now: () => number;
  private readonly ttlMs: number;
  private readonly flashMs: number;
  private readonly waveMs: number;

  constructor(opts: Options = {}) {
    this.now = opts.now ?? Date.now;
    this.ttlMs = opts.ttlMs ?? 15 * 60_000;
    this.flashMs = opts.flashMs ?? 2500;
    this.waveMs = opts.waveMs ?? 1500;
  }

  apply(event: NormalizedEvent): void {
    const key = `${event.agent}:${event.sessionId}`;
    if (event.phase === "idle") {
      this.sessions.delete(key);
      return;
    }
    const now = this.now();
    const prev = this.sessions.get(key);
    this.sessions.set(key, {
      key,
      agent: event.agent,
      sessionId: event.sessionId,
      project: event.project,
      phase: event.phase,
      tool: event.tool,
      startedAt: prev?.startedAt ?? event.ts,
      lastEventAt: now,
    });
    if (event.phase === "started") this.flash = { state: "waving", until: now + this.waveMs };
    if (event.phase === "done") this.flash = { state: "jumping", until: now + this.flashMs };
    if (event.phase === "failed") this.flash = { state: "failed", until: now + this.flashMs };
  }

  sweep(): void {
    const cutoff = this.now() - this.ttlMs;
    for (const [key, session] of this.sessions) if (session.lastEventAt < cutoff) this.sessions.delete(key);
  }

  petState(): PetState {
    this.sweep();
    const sessions = [...this.sessions.values()];
    if (sessions.some((s) => s.phase === "waiting")) return "waiting";
    if (this.flash && this.now() < this.flash.until) return this.flash.state;
    if (sessions.some((s) => s.phase === "review")) return "review";
    if (sessions.some((s) => s.phase === "working")) return "running";
    return "idle";
  }

  snapshot(activePet: string | null, extra: Extra): Snapshot {
    this.sweep();
    const sessions = [...this.sessions.values()].sort((a, b) => (PHASE_ORDER[a.phase] - PHASE_ORDER[b.phase]) || (b.lastEventAt - a.lastEventAt));
    return { type: "snapshot", now: this.now(), pet: this.petState(), sessions, activePet, ...extra };
  }
}

import { join } from "node:path";

export interface LocalPet {
  id: string;
  source: "local";
  slug: string;
  name: string;
  dir: string;
  spriteFile: string;
}

export type AtlasLayout = { version: 1 | 2; rows: 9 | 11; width: number; height: number };
const SLUG_RE = /^[a-z0-9][a-z0-9._-]{0,63}$/i;

export function detectAtlas(width: number, height: number): AtlasLayout | null {
  if (!Number.isInteger(width) || !Number.isInteger(height) || width <= 0 || height <= 0) return null;
  for (const rows of [9, 11] as const) {
    if (width % 8 !== 0 || height % rows !== 0) continue;
    if (width * rows * 208 !== height * 8 * 192) continue;
    return { version: rows === 9 ? 1 : 2, rows, width, height };
  }
  return null;
}

export function readImageSize(buf: Buffer): { width: number; height: number } | null {
  if (buf.length >= 24 && buf[0] === 0x89 && buf.toString("ascii", 1, 4) === "PNG") {
    return { width: buf.readUInt32BE(16), height: buf.readUInt32BE(20) };
  }
  if (buf.length >= 30 && buf.toString("ascii", 0, 4) === "RIFF" && buf.toString("ascii", 8, 12) === "WEBP") {
    const chunk = buf.toString("ascii", 12, 16);
    if (chunk === "VP8X") return { width: 1 + buf.readUIntLE(24, 3), height: 1 + buf.readUIntLE(27, 3) };
    if (chunk === "VP8 ") return { width: buf.readUInt16LE(26) & 0x3fff, height: buf.readUInt16LE(28) & 0x3fff };
  }
  return null;
}

export function scanLocalPets(dirs: string[]): LocalPet[] {
  const pets: LocalPet[] = [];
  for (const dir of dirs) {
    if (!existsSync(dir)) continue;
    for (const entry of readdirSync(dir, { withFileTypes: true })) {
      if (!entry.isDirectory() || !SLUG_RE.test(entry.name)) continue;
      const petDir = join(dir, entry.name);
      const petJson = join(petDir, "pet.json");
      if (!existsSync(petJson)) continue;
      try {
        const meta = JSON.parse(readFileSync(petJson, "utf8")) as { displayName?: unknown; name?: unknown };
        const name = typeof meta.displayName === "string" ? meta.displayName : typeof meta.name === "string" ? meta.name : entry.name;
        const spriteFile = ["spritesheet.webp", "spritesheet.png"].find((file) => existsSync(join(petDir, file)));
        if (!spriteFile) continue;
        pets.push({ id: `local:${entry.name}`, source: "local", slug: entry.name, name, dir: petDir, spriteFile });
      } catch {
        continue;
      }
    }
  }
  return pets;
}

export function validateLocalPet(pet: LocalPet): { ok: true } | { ok: false; error: string } {
  const size = readImageSize(readFileSync(join(pet.dir, pet.spriteFile)));
  if (!size) return { ok: false, error: "unsupported spritesheet (need PNG or WebP)" };
  if (!detectAtlas(size.width, size.height)) return { ok: false, error: `spritesheet ${size.width}x${size.height} is not an 8x9 or 8x11 Petdex atlas` };
  return { ok: true };
}

import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname } from "node:path";

export interface PetdexPet {
  id: string;
  source: "petdex";
  slug: string;
  name: string;
  spritesheetUrl: string;
  petJsonUrl: string;
}

type Options = {
  cacheFile: string;
  url?: string;
  fetchImpl?: typeof fetch;
  maxAgeMs?: number;
  now?: () => number;
};

function toPet(value: Record<string, unknown>): PetdexPet | null {
  const slug = typeof value.slug === "string" ? value.slug : null;
  const name = typeof value.displayName === "string" ? value.displayName : slug;
  const spritesheetUrl = typeof value.spritesheetUrl === "string" ? value.spritesheetUrl : null;
  const petJsonUrl = typeof value.petJsonUrl === "string" ? value.petJsonUrl : null;
  if (!slug || !name || !spritesheetUrl || !petJsonUrl) return null;
  if (!/^[a-z0-9][a-z0-9._-]{0,63}$/i.test(slug)) return null;
  return { id: `petdex:${slug}`, source: "petdex", slug, name, spritesheetUrl, petJsonUrl };
}

export async function loadPetdexPets(opts: Options): Promise<PetdexPet[]> {
  const url = opts.url ?? "https://petdex.dev/api/manifest";
  const fetchImpl = opts.fetchImpl ?? fetch;
  const now = opts.now ?? Date.now;
  const maxAge = opts.maxAgeMs ?? 24 * 60 * 60_000;
  let cached: { fetchedAt: number; pets: PetdexPet[] } | null = null;
  if (existsSync(opts.cacheFile)) {
    try {
      cached = JSON.parse(readFileSync(opts.cacheFile, "utf8")) as { fetchedAt: number; pets: PetdexPet[] };
    } catch {
      cached = null;
    }
  }
  if (cached && now() - cached.fetchedAt < maxAge) return cached.pets;
  try {
    const response = await fetchImpl(url, { signal: AbortSignal.timeout(10_000) });
    if (!response.ok) throw new Error(`manifest ${response.status}`);
    const data = (await response.json()) as { pets?: unknown };
    const pets = Array.isArray(data.pets)
      ? data.pets.filter((p): p is Record<string, unknown> => typeof p === "object" && p !== null).map(toPet).filter((p): p is PetdexPet => p !== null)
      : [];
    mkdirSync(dirname(opts.cacheFile), { recursive: true });
    writeFileSync(opts.cacheFile, JSON.stringify({ fetchedAt: now(), pets }));
    return pets;
  } catch {
    return cached?.pets ?? [];
  }
}

import type { IncomingMessage, ServerResponse } from "node:http";

export function isLoopback(address: string | undefined): boolean {
  return address === "127.0.0.1" || address === "::1" || address === "::ffff:127.0.0.1";
}

function cookieToken(req: IncomingMessage): string | null {
  const header = req.headers.cookie;
  if (!header) return null;
  for (const part of header.split(";")) {
    const index = part.indexOf("=");
    if (index === -1) continue;
    if (part.slice(0, index).trim() === "foldpet_token") return decodeURIComponent(part.slice(index + 1));
  }
  return null;
}

export function requestToken(req: IncomingMessage, url: URL): string | null {
  const auth = req.headers.authorization;
  if (auth?.startsWith("Bearer ")) return auth.slice(7);
  return url.searchParams.get("token") ?? cookieToken(req);
}

export function isAuthorized(req: IncomingMessage, url: URL, token: string): boolean {
  return requestToken(req, url) === token;
}

export function setTokenCookie(res: ServerResponse, token: string): void {
  res.setHeader("Set-Cookie", `foldpet_token=${encodeURIComponent(token)}; HttpOnly; SameSite=Lax; Path=/`);
}

type IfaceMap = NodeJS.Dict<NetworkInterfaceInfo[]>;

export function urlsForPort(port: number, token: string, ifaces: IfaceMap = networkInterfaces()): string[] {
  const ranked: Array<{ url: string; rank: number }> = [];
  for (const [name, addrs] of Object.entries(ifaces)) {
    for (const addr of addrs ?? []) {
      if (addr.family !== "IPv4" || addr.internal || addr.address.startsWith("169.254.")) continue;
      const rank = name.startsWith("en") ? 0 : name.startsWith("utun") ? 2 : 1;
      ranked.push({ url: `http://${addr.address}:${port}/?token=${encodeURIComponent(token)}`, rank });
    }
  }
  ranked.sort((a, b) => a.rank - b.rank);
  return [...new Set(ranked.map((item) => item.url))];
}

  return Buffer.concat(chunks).toString("utf8");
}
function safeJoin(root: string, rel: string): string | null {
  const base = resolve(root);
  const target = resolve(base, "." + (rel.startsWith("/") ? rel : "/" + rel));
  return target === base || target.startsWith(base + sep) ? target : null;
}
function petdexUrlAllowed(raw: string): boolean {
  try {
    const url = new URL(raw);
    return url.protocol === "https:" && (url.hostname === "petdex.dev" || url.hostname.endsWith(".petdex.dev"));
  } catch {
    return false;
  }
}
function serveFile(res: ServerResponse, file: string): void {
  res.writeHead(200, { "content-type": MIME[extname(file)] ?? "application/octet-stream" });
  res.end(readFileSync(file));

        broadcast();
        return res.writeHead(204).end();

        if (!isLoopback(req.socket.remoteAddress)) return text(res, 403, "loopback only");
        return json(res, 200, { ok: true, sessions: aggregator.snapshot(null, { sleepAfterMinutes: 0, quietHours: null }).sessions.length });

        if (!existsSync(file)) return text(res, 500, "web build missing: npm run build:web");
        return serveFile(res, file);
      }

        const file = safeJoin(opts.webDist, path.slice("/assets/web".length));
        if (!file || !existsSync(file)) return text(res, 404, "not found");
        return serveFile(res, file);
      }
      if (req.method === "GET" && path === "/api/state") return json(res, 200, snapshot());
      if (req.method === "GET" && path === "/api/pets") return json(res, 200, { pets: await petSummaries() });
      if (req.method === "PUT" && path === "/api/active-pet") {
        let value: unknown;
        try { value = JSON.parse(await readBody(req)); } catch { return text(res, 400, "invalid json"); }
        const id = (value as { id?: unknown })?.id;
        if (typeof id !== "string") return text(res, 400, "id required");
        if (!(await petSummaries()).some((pet) => pet.id === id)) return text(res, 400, "unknown pet");
        config.activePet = id;
        saveConfig(home, config);
        broadcast();
        return res.writeHead(204).end();
      }
      if (req.method === "GET" && path.startsWith("/assets/pets/local/")) {
        const parts = path.slice("/assets/pets/local/".length).split("/");
        if (parts.length !== 2 || !SLUG.test(parts[0]!)) return text(res, 404, "not found");
        const pet = scanLocalPets(localPetDirs).find((candidate) => candidate.slug === parts[0]);
        if (!pet) return text(res, 404, "not found");
        const file = parts[1]!;
        if (file !== "pet.json" && file !== pet.spriteFile) return text(res, 404, "not found");
        const target = join(pet.dir, file);
        if (!existsSync(target)) return text(res, 404, "not found");
        return serveFile(res, target);
      }
      if (req.method === "GET" && path.startsWith("/assets/pets/petdex/")) {
        const parts = path.slice("/assets/pets/petdex/".length).split("/");
        if (parts.length !== 2 || !SLUG.test(parts[0]!)) return text(res, 404, "not found");
        const pet = (await listPets()).petdex.find((candidate) => candidate.slug === parts[0]);
        if (!pet) return text(res, 404, "not found");
        const spriteName = basename(new URL(pet.spritesheetUrl).pathname);
        const source = parts[1] === "pet.json" ? pet.petJsonUrl : parts[1] === spriteName ? pet.spritesheetUrl : null;
        if (!source || !petdexUrlAllowed(source)) return text(res, 404, "not found");
        const cacheDir = join(home, "cache", "petdex", pet.slug);
        const cachePath = join(cacheDir, parts[1]!);
        if (!existsSync(cachePath)) {
          const upstream = await fetchImpl(source, { signal: AbortSignal.timeout(10_000) });
          if (!upstream.ok) return text(res, 502, "upstream error");
          mkdirSync(cacheDir, { recursive: true });
          writeFileSync(cachePath, Buffer.from(await upstream.arrayBuffer()));
        }
        return serveFile(res, cachePath);
      }
      return text(res, 404, "not found");
    } catch (error) {
      return json(res, 500, { error: error instanceof Error ? error.message : "internal error" });
    }
  });

  const wss = new WebSocketServer({ noServer: true });
  server.on("upgrade", (req, socket, head) => {
    const url = new URL(req.url ?? "/", "http://localhost");
    if (url.pathname !== "/ws" || !isAuthorized(req, url, config.token)) {
      socket.write("HTTP/1.1 401 Unauthorized\r\n\r\n");
      socket.destroy();
      return;
    }
    wss.handleUpgrade(req, socket, head, (ws) => wss.emit("connection", ws, req));
  });
  wss.on("connection", (ws) => {
    wsClients.add(ws);
    ws.send(JSON.stringify(snapshot()));
    ws.on("close", () => wsClients.delete(ws));
    ws.on("error", () => wsClients.delete(ws));
  });

  await new Promise<void>((resolveListen, reject) => {
    server.once("error", reject);
    server.listen(opts.port ?? config.port, "0.0.0.0", () => resolveListen());
  });
  const address = server.address();
  const port = typeof address === "object" && address ? address.port : (opts.port ?? config.port);

  return {
    port,
    config,
    aggregator,
    broadcast,
    close: async () => {
      for (const client of wsClients) client.close();
      wss.close();
      await new Promise<void>((resolveClose) => server.close(() => resolveClose()));
    },
  };
}

import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname } from "node:path";

export const CLAUDE_HOOK_EVENTS = ["SessionStart", "UserPromptSubmit", "PreToolUse", "PostToolUse", "Notification", "SubagentStop", "Stop", "SessionEnd"] as const;
export const HOOK_COMMAND = "fold-pet hook claude";

type Entry = { hooks?: Array<{ type?: string; command?: string }> };

export function installClaudeHooks(settingsPath: string, command = HOOK_COMMAND): { added: string[]; already: string[] } {
  let settings: Record<string, unknown> = {};
  if (existsSync(settingsPath)) {
    try {
      settings = JSON.parse(readFileSync(settingsPath, "utf8")) as Record<string, unknown>;
    } catch {
      throw new Error(`invalid Claude settings JSON: ${settingsPath}`);
    }
  }
  const hooks = (settings.hooks ?? {}) as Record<string, Entry[]>;
  const added: string[] = [];
  const already: string[] = [];
  for (const event of CLAUDE_HOOK_EVENTS) {
    const entries = Array.isArray(hooks[event]) ? hooks[event]! : [];
    const present = entries.some((entry) => (entry.hooks ?? []).some((hook) => hook.type === "command" && hook.command === command));
    if (present) {
      already.push(event);
      continue;
    }
    entries.push({ hooks: [{ type: "command", command }] });
    hooks[event] = entries;
    added.push(event);
  }
  settings.hooks = hooks;
  mkdirSync(dirname(settingsPath), { recursive: true });
  writeFileSync(settingsPath, JSON.stringify(settings, null, 2) + "\n");
  return { added, already };
}

import { connect } from "node:net";

export type Check = { name: string; status: "PASS" | "WARN" | "FAIL"; detail: string };
type Options = { home: string; settingsPath?: string; localPetDirs?: string[]; probePort?: (port: number) => Promise<boolean> };

function probe(port: number): Promise<boolean> {
  return new Promise((resolve) => {
    const socket = connect({ host: "127.0.0.1", port });
    socket.setTimeout(300);
    socket.once("connect", () => { socket.destroy(); resolve(true); });
    socket.once("timeout", () => { socket.destroy(); resolve(false); });
    socket.once("error", () => resolve(false));
  });
}

function claudeHookCheck(settingsPath: string): Check {
  if (!existsSync(settingsPath)) return { name: "claude hooks", status: "FAIL", detail: `settings not found: ${settingsPath}` };
  try {
    const settings = JSON.parse(readFileSync(settingsPath, "utf8")) as { hooks?: Record<string, Array<{ hooks?: Array<{ command?: string }> }>> };
    const missing = CLAUDE_HOOK_EVENTS.filter((event) => !(settings.hooks?.[event] ?? []).some((entry) => (entry.hooks ?? []).some((hook) => hook.command === HOOK_COMMAND)));
    return missing.length === 0 ? { name: "claude hooks", status: "PASS", detail: "all events wired" } : { name: "claude hooks", status: "FAIL", detail: `missing: ${missing.join(", ")}` };
  } catch {
    return { name: "claude hooks", status: "FAIL", detail: "invalid settings JSON" };
  }
}

export async function doctorChecks(opts: Options): Promise<Check[]> {
  const checks: Check[] = [];
  const major = Number(process.versions.node.split(".")[0]);
  checks.push({ name: "node", status: major >= 20 ? "PASS" : "FAIL", detail: process.versions.node });

  let config = null as ReturnType<typeof loadConfig> | null;
  try {
    config = loadConfig(opts.home);
    checks.push({ name: "config", status: "PASS", detail: configPath(opts.home) });
  } catch (error) {
    checks.push({ name: "config", status: "FAIL", detail: error instanceof Error ? error.message : "invalid" });
  }

  const settingsPath = opts.settingsPath ?? join(process.env.CLAUDE_CONFIG_DIR ?? join(homedir(), ".claude"), "settings.json");
  checks.push(claudeHookCheck(settingsPath));

  const pets = scanLocalPets(opts.localPetDirs ?? [join(opts.home, "pets"), join(homedir(), ".codex", "pets")]);
  checks.push(pets.length > 0 ? { name: "pets", status: "PASS", detail: `${pets.length} local pet(s)` } : { name: "pets", status: "WARN", detail: "none found; run npx petdex install boba" });

  if (config) {
    const open = await (opts.probePort ?? probe)(config.port);
    checks.push({ name: "bridge", status: open ? "PASS" : "WARN", detail: open ? `listening on ${config.port}` : `not listening on ${config.port}; run fold-pet run` });
  }
  return checks;
}

export type ConnStatus = "connecting" | "open" | "closed";

export function connectState(onSnapshot: (snapshot: unknown) => void, onStatus: (status: ConnStatus) => void): () => void {
  let socket: WebSocket | null = null;
  let disposed = false;
  let attempt = 0;
  let timer: number | undefined;

  const open = (): void => {
    if (disposed) return;
    onStatus("connecting");
    const protocol = location.protocol === "https:" ? "wss" : "ws";
    socket = new WebSocket(`${protocol}://${location.host}/ws`);
    socket.onopen = () => { attempt = 0; onStatus("open"); };
    socket.onmessage = (event) => {
      try {
        const data = JSON.parse(String(event.data));
        if (data?.type === "snapshot") onSnapshot(data);
      } catch {
        return;
      }
    };
    socket.onclose = () => {
      if (disposed) return;
      onStatus("closed");
      const delay = Math.min(30_000, 1000 * 2 ** attempt++);
      timer = window.setTimeout(open, delay);
    };
    socket.onerror = () => socket?.close();
  };

  open();
  return () => {
    disposed = true;
    if (timer) window.clearTimeout(timer);
    socket?.close();
  };
}

export type PetState = "idle" | "running-right" | "running-left" | "waving" | "jumping" | "failed" | "waiting" | "running" | "review";

type StateDef = { row: number; frames: number[] };
const FRAME_W = 192;
const FRAME_H = 208;
const COLUMNS = 8;

function uniform(count: number, duration: number, last: number): number[] {
  return Array.from({ length: count }, (_, index) => (index === count - 1 ? last : duration));
}

const STATES: Record<PetState, StateDef> = {
  idle: { row: 0, frames: [280, 110, 110, 140, 140, 320] },
  "running-right": { row: 1, frames: uniform(8, 120, 220) },
  "running-left": { row: 2, frames: uniform(8, 120, 220) },
  waving: { row: 3, frames: uniform(4, 140, 280) },
  jumping: { row: 4, frames: uniform(5, 140, 280) },
  failed: { row: 5, frames: uniform(8, 140, 240) },
  waiting: { row: 6, frames: uniform(6, 150, 260) },
  running: { row: 7, frames: uniform(6, 120, 220) },
  review: { row: 8, frames: uniform(6, 150, 280) },
};

export class PetRenderer {
  private image: HTMLImageElement | null = null;
  private state: PetState = "idle";
  private frame = 0;
  private last = performance.now();
  private raf = 0;

  constructor(private canvas: HTMLCanvasElement) {}

  async load(url: string): Promise<void> {
    const image = new Image();
    image.src = url;
    await image.decode();
    this.image = image;
    this.frame = 0;
  }

  setState(state: PetState): void {
    if (state === this.state) return;
    this.state = state;
    this.frame = 0;
  }

  start(): void {
    cancelAnimationFrame(this.raf);
    const loop = (now: number): void => {
      this.draw(now);
      this.raf = requestAnimationFrame(loop);
    };
    this.last = performance.now();
    this.raf = requestAnimationFrame(loop);
  }

  stop(): void {
    cancelAnimationFrame(this.raf);
  }

  private draw(now: number): void {
    const ctx = this.canvas.getContext("2d");
    if (!ctx) return;
    const def = STATES[this.state];
    if (now - this.last >= (def.frames[this.frame] ?? 150)) {
      this.frame = (this.frame + 1) % def.frames.length;
      this.last = now;
    }
    ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);
    if (this.image) {
      ctx.imageSmoothingEnabled = false;
      ctx.drawImage(this.image, (this.frame % COLUMNS) * FRAME_W, def.row * FRAME_H, FRAME_W, FRAME_H, 0, 0, this.canvas.width, this.canvas.height);
      return;
    }
    const bob = Math.sin(now / 500) * (this.state === "idle" ? 3 : 1);
    ctx.fillStyle = this.state === "failed" ? "#ef4444" : this.state === "waiting" ? "#f59e0b" : "#7dd3fc";

      await renderer.load(pet.spriteUrl);
      stage.dataset.petReady = "true";
    } catch {
      stage.dataset.petReady = "false";

export function isQuiet(range: { start: string; end: string } | null, date: Date): boolean {
  if (!range) return false;
  const toMinutes = (value: string): number => {
    const [hours, minutes] = value.split(":").map(Number);
    return (hours ?? 0) * 60 + (minutes ?? 0);
  };
  const now = date.getHours() * 60 + date.getMinutes();
  const start = toMinutes(range.start);
  const end = toMinutes(range.end);
  return start <= end ? now >= start && now < end : now >= start || now < end;
}

export type WakeStatus = "active" | "unsupported" | "denied" | "insecure" | "idle";

export function keepAwake(onChange: (status: WakeStatus) => void): () => void {
  let sentinel: WakeLockSentinel | null = null;
  let disposed = false;

  const acquire = async (): Promise<void> => {
    if (disposed) return;
    if (!window.isSecureContext) { onChange("insecure"); return; }
    if (!("wakeLock" in navigator)) { onChange("unsupported"); return; }
    try {
      sentinel = await navigator.wakeLock.request("screen");
      onChange("active");
      sentinel.addEventListener("release", () => { sentinel = null; if (!disposed) onChange("idle"); });
    } catch {
      onChange("denied");
    }
  };

  const onVisibility = (): void => { if (document.visibilityState === "visible" && !sentinel) void acquire(); };
  document.addEventListener("visibilitychange", onVisibility);
  void acquire();

  return () => {
    disposed = true;
    document.removeEventListener("visibilitychange", onVisibility);
    sentinel?.release().catch(() => undefined);
  };
}

```markdown
# FoldPet

Turn a foldable phone into a desk clock with a live AI-agent pet. The Mac bridge collects coding-agent activity and streams it to a phone web page — no app install, no cloud.

## Requirements

- macOS with Node.js >= 20
- Phone on the same WiFi as the Mac, or the Mac joined to the phone's Bluetooth tethering
- Claude Code for the M1 adapter

## Setup

```bash
npm install
npm run build
npm link          # gives a stable `fold-pet` command for Claude hooks
fold-pet init     # creates ~/.fold-pet/config.json and wires Claude Code hooks
fold-pet run      # prints LAN URLs and a QR code
```

Scan the QR on the phone, add the page to the home screen, and keep it open while charging.

## Always-on screen

The page requests the Screen Wake Lock when the browser allows it. Over plain HTTP on a LAN IP the API is unavailable, so set the phone's auto-lock to Never (iOS) or extend the screen timeout / enable Stay awake (Android). A one-time local HTTPS certificate option may come later.

## Bluetooth tethering

When the Mac and phone are on different networks: pair them once, enable the phone's Personal Hotspot / Bluetooth tethering, join it from the Mac, then restart `fold-pet run` and rescan the QR (the bridge prints the new address). Pet state is tiny; the slow link is fine.

## Pets

- Install from the Petdex gallery: `npx petdex install boba` (lands in `~/.codex/pets`).
- Or drop a pet folder (`pet.json` + `spritesheet.webp|png`, 8×9 or 8×11 atlas) into `~/.fold-pet/pets`.
- Pick the active pet from the phone's gear drawer. Use the same Petdex slug on desktop to show the same character.

## Commands

- `fold-pet init` — create config and Claude hooks
- `fold-pet run` — start the bridge and print the QR
- `fold-pet doctor` — check config, hooks, pets, port
- `fold-pet hook claude` — internal; called by Claude Code hooks

## Status

M1: Claude Code adapter, phone display (folded + wide), pet catalog, QR pairing. Codex/OpenCode/Pi adapters, Qoder support, pet upload, and guided Bluetooth setup are later milestones. See `docs/superpowers/specs/2026-11-21-fold-pet-design.md`.

## Security

Events are accepted only from loopback. The phone API requires the per-install token; the QR carries it once and the browser stores it as an HttpOnly cookie. No cloud, no telemetry. Events contain agent/session/project/tool names only — never code, prompts, or outputs.
