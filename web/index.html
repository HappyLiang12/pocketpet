Troubleshooting

ERR_TOO_MANY_RETRIES / ERR_SSL_PROTOCOL_ERROR

Chrome/Edge “Always use secure connections” or a VPN forces HTTPS on the HTTP address. Turn it off, try Safari/Firefox, or on iPhone disable VPN/iCloud Private Relay.

unauthorized

You opened the cleaned / URL without the token. Scan the QR code or use the tokenized URL listed on /setup.

Setup page opens on the computer

/setup only opens on the computer running PocketPet; phones scan the QR code or open the link shown there.

Cannot reach the computer

Confirm the phone and the computer are on the same WiFi/subnet (guest networks and AP isolation block it), or use USB: adb reverse tcp:7788 tcp:7788.
